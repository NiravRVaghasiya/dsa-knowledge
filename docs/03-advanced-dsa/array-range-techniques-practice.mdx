## 🐍 Difference array + sweep line

<PythonRunner
  title="🐍 Range-add (difference array) and max-overlap (sweep line)"
  height={480}
  code={`def apply_range_updates(n, updates):        # difference array
    diff = [0]*(n+1)
    for l, r, v in updates:
        diff[l] += v
        diff[r+1] -= v                       # cancel just past r
    a, run = [0]*n, 0
    for i in range(n):
        run += diff[i]                       # integrate = prefix sum
        a[i] = run
    return a

def max_overlap(intervals):                  # sweep line
    events = []
    for s, e in intervals:
        events.append((s, +1))               # interval becomes active
        events.append((e, -1))               # becomes inactive
    events.sort(key=lambda x: (x[0], x[1]))  # ties: -1 before +1 (half-open)
    active = best = 0
    for _, d in events:
        active += d
        best = max(best, active)
    return best

print(apply_range_updates(5, [(0,2,3),(1,4,2),(3,3,5)]))   # [3,5,5,7,2]
print(max_overlap([(0,30),(5,10),(15,20)]))                # 2 (rooms needed)
`}
/>

## 🐍 Coordinate compression

<PythonRunner
  title="🐍 Collapse a huge sparse range to dense ranks"
  height={320}
  code={`def compress(values):
    sorted_unique = sorted(set(values))
    rank = {v: i for i, v in enumerate(sorted_unique)}
    return [rank[v] for v in values], sorted_unique

vals = [100, 5, 100, 90_000_000, 5]
comp, mapping = compress(vals)
print("compressed:", comp)     # [1, 0, 1, 2, 0]  -- ranks in 0..2
print("map back:  ", mapping)  # [5, 100, 90000000]
`}
