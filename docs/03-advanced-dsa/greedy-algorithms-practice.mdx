Companion to the **[Greedy Algorithms guide](/docs/greedy-algorithms)**. Interval scheduling: greedily pick the most non-overlapping meetings. Edit and run the code right here — it executes in your browser.

  code={`# Maximum non-overlapping intervals — greedy by earliest finish time.
def max_meetings(intervals):
    intervals.sort(key=lambda x: x[1])   # sort by end time
    count = 0
    last_end = float("-inf")
    for s, e in intervals:
        if s >= last_end:
            count += 1
            last_end = e
    return count

print(max_meetings([(1,4),(2,3),(3,5),(0,6),(5,7),(8,9)]))   # -> 4
`}
