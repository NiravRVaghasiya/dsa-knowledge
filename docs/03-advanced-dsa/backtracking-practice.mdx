## 🐍 Your turn

<PythonRunner
  title="🐍 Backtracking — Practice"
  height={380}
  code={`# Generate all subsets (the power set) via backtracking.
def subsets(nums):
    res = []
    def backtrack(start, path):
        res.append(path[:])            # record current subset
        for i in range(start, len(nums)):
            path.append(nums[i])       # choose
            backtrack(i + 1, path)     # explore
            path.pop()                 # un-choose (backtrack)
    backtrack(0, [])
    return res

print(subsets([1, 2, 3]))
# -> [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]
`}
/>

## 🧠 Challenge yourself

1. Generate all **permutations** instead of subsets.
