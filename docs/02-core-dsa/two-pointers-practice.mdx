## 🎬 Watch it work: Two Sum on a sorted array

The **converging pointers** pattern: start at both ends, move inward based on whether the current sum is too small or too big. Press **Play** (or step through) to see why it's O(n) instead of O(n²).

**Why it works:** because the array is sorted, if the sum is too small the only way to increase it is to move the left pointer right; if too big, move the right pointer left. Every step eliminates one candidate, so we touch each element at most once.

<PythonRunner

  code={`# Two Sum II — sorted array, return the two indices (1-based) that sum to target.
# Implement the two-pointer solution. Aim for O(n) time, O(1) space.

def two_sum_sorted(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return [left + 1, right + 1]
        elif s < target:
            left += 1
        else:
            right -= 1
    return []

# Tests
print(two_sum_sorted([2, 3, 5, 8, 11, 15], 13))  # -> [1, 5]  (2 + 11 = 13)
print(two_sum_sorted([1, 2, 3, 4, 4, 9, 56, 90], 8))  # -> [4, 5]  (4 + 4 = 8)
print(two_sum_sorted([-1, 0, 3, 7], 10))  # -> [3, 4]  (3 + 7 = 10)
`}
