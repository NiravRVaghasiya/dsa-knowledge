  title="🐍 Sorting Algorithms — Practice"
  height={380}
  code={`# Implement insertion sort — build the sorted portion one element at a time.
def insertion_sort(a):
    a = a[:]                      # don't mutate the caller's list
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a

print(insertion_sort([5, 2, 8, 1, 4]))   # -> [1, 2, 4, 5, 8]
print(insertion_sort([9, 7, 5, 3, 1]))   # -> [1, 3, 5, 7, 9]
`}

## 🧠 Challenge yourself

1. Modify it to sort in **descending** order.
2. Count the number of swaps — which input order maximizes them?
3. Why is insertion sort O(n) on an already-sorted array but O(n²) worst case?
